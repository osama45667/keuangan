🏗️ CSS Layer Stack (Z-Index Hierarchy)

Layer 1: Body └─ background-image: url(...) └─ background-size: cover └─ background-attachment: fixed Layer 2: Body::before (Overlay) └─ position: fixed (full viewport) └─ background: linear-gradient(180deg, rgba(2,6,23,0.55), rgba(2,6,23,0.70)) └─ z-index: 2 └─ pointer-events: none Layer 10: Main Content (.card, .container) └─ background: rgba(255, 255, 255, 0.86) └─ backdrop-filter: blur(12px) └─ position: relative, z-index: 10 └─ border-radius: 14px Layer 20: Header & Footer └─ background: rgba(248, 250, 252, 0.92) └─ backdrop-filter: blur(12px) └─ z-index: 20

👁️ Apa Yang Seharusnya Terlihat

  • ✓ Background image terlihat di belakang kartu
  • ✓ Overlay gelap di atas background (gradient fade)
  • ✓ Content card dengan background semi-transparent putih
  • ✓ Blur effect (glassmorphism) pada semua layer
  • ✓ Text readable dengan kontras yang baik
  • ✓ Header dan footer tetap visible di atas semua

💻 HTML Structure Minimal

Struktur HTML yang digunakan:

<html> <head> <style> body { background-image: url(...) } body::before { z-index: 2; /* overlay */ } .card { z-index: 10; background: rgba(...) } </style> </head> <body> <header z-index="20">...</header> <main z-index="10"> <div class="card">...</div> </main> <footer z-index="20">...</footer> </body> </html>

✅ Testing Checklist

  • Visual Test: Apakah background image visible di belakang kartu?
  • Overlay Test: Apakah ada gelap gradient di atas background?
  • Blur Test: Apakah content card terlihat blur/frosted glass?
  • Readability Test: Apakah text cukup readable dan tidak terlalu gelap?
  • Responsive Test: Coba resize browser, background tetap fixed?
  • Cache Test: Tekan Ctrl+F5 untuk hard refresh tanpa cache

🔧 Jika Masih Ada Masalah

Langkah debugging:

  • 1. Clear Cache: Ctrl+Shift+Delete → Cached images and files
  • 2. Hard Refresh: Ctrl+F5 untuk reload tanpa cache
  • 3. DevTools Inspect: F12 → Cek computed styles di body element
  • 4. Network Check: DevTools → Network tab → Cek status image (200 OK)
  • 5. Console Errors: Lihat Console tab untuk JS errors
  • 6. Try Different Browser: Test di Chrome, Firefox, Edge
