🔍 Background Feature Debug Panel

1. Inspect Current Page CSS

Open DevTools (F12) and run this in Console:

// Check body classes
console.log('Body classes:', document.body.className);

// Check inline style
console.log('Body inline style:', document.body.getAttribute('style'));

// Check computed styles
const computed = window.getComputedStyle(document.body);
console.log('Background image:', computed.backgroundImage);
console.log('Background:', computed.background);

// Check if .has-bg class present
console.log('Has .has-bg class:', document.body.classList.contains('has-bg'));

// Check ::before pseudo element
const beforeStyle = window.getComputedStyle(document.body, '::before');
console.log('::before exists:', beforeStyle.content !== 'none');

2. Check App CSS File

Inspect these CSS rules:

.app-body { 
    background: linear-gradient(...);  ← Default gradient
}

.app-body.has-bg { 
    background: none !important;       ← Removes gradient
}

.app-body.has-bg::before {
    content: '';
    position: fixed;
    background: linear-gradient(...); ← Overlay effect
    z-index: 1;
}

.app-body.has-bg .app-main {
    background: rgba(255, 255, 255, 0.55);  ← Content blur
    backdrop-filter: blur(12px);
}

3. Test Inline Style Application

↑ If this box shows a blue gradient, background-image inline style works ✓

4. Quick Checklist

  • ✓ Form loads without JavaScript errors? (Check Console)
  • ✓ Upload image works? (Try uploading)
  • ✓ Save Changes submits? (Try saving)
  • ✓ Page refreshes after save?
  • ✓ Body tag has class="app-body has-bg"?
  • ✓ Body has inline style with background-image?
  • ✓ CSS file loads? (Check Network tab, app.css ~80KB)
  • ✓ Background image visible? (Should see it full screen)
  • ✓ Overlay visible? (Dark/light tint on top)
  • ✓ Content has blur? (Page content should look blurred)

5. If Background Still Not Showing

Step 1: Open DevTools (F12) → Elements tab

Step 2: Check body tag attributes:

<body class="app-body has-bg theme-overlay-auto" 
      style="background-image: url('/storage/themes/...')">

Step 3: If class/style missing → Form not saving correctly

Step 4: If class/style present → CSS rule issue

Step 5: If image URL 404 → Storage/symlink issue
