If Background NOT Visible:

  • Check browser DevTools (F12)
  • Look under Inspector → head/body
  • Verify background-image URL is correct
  • Check if CSS is being loaded and parsed
  • Try different browser (Chrome, Firefox, Edge)
  • Clear browser cache (Ctrl+Shift+Delete)

Production Implementation

In the actual Keuangan app, this same approach applies:

Step 1: User uploads image in Profile Settings
Step 2: Image stored in storage/app/public/themes/
Step 3: Path saved to users table
Step 4: On page load, layout.app.blade.php checks user theme
Step 5: Background-image style applied inline to body
Step 6: Overlay gradient added via ::before pseudo-element
Step 7: Content shows through semi-transparent background

Troubleshooting Checklist

☐ Theme image uploaded successfully
☐ Image URL accessible in browser
☐ Database has theme_bg_path value
☐ Body tag has 'has-bg' class
☐ Inline style has background-image
☐ CSS loaded without errors
☐ No conflicting CSS rules
☐ Browser cache cleared
☐ JavaScript not blocking styles
