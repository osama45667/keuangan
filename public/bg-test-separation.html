✅ Background Rendering Test (Separation Method)

Approach: Separate Fixed Background Container

  • Background image di fixed pseudo-element (z-index: -2)
  • Overlay di fixed pseudo-element (z-index: -1)
  • Content di z-index: 1 dengan semi-transparent background

Keuntungan:

  • ✓ Tidak ada issue dengan multiple backgrounds
  • ✓ Overlay always on top of image
  • ✓ Content tetap readable
  • ✓ Better browser compatibility

Jika Anda lihat gambar di background:

  • ✓ Background-image URL bekerja
  • ✓ Storage disk berfungsi
  • ✓ Render engine OK

QA Checklist:

  • ☐ Background image terlihat di belakang content
  • ☐ Overlay membuat gambar lebih gelap
  • ☐ Gambar tidak bergerak saat scroll (fixed)
  • ☐ Content tetap readable
