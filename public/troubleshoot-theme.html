🎨 Background Theme Feature - Troubleshooting Guide

Quick Checklist

1. Hard refresh browser: Press Ctrl+Shift+Delete to clear cache, then refresh page
2. Open DevTools: Press F12 to open browser developer tools
3. Check console: Go to Console tab, look for any red errors
4. Check HTML: Right-click on body tag → Inspect Element
5. Verify HTML structure: Look for:
  • <body class="app-body has-bg theme-overlay-...">
  • style="background-image: url(...); ..."
6. Check file exists: Open /storage/themes/filename.png directly in new tab - image should download

Step 1: Verify File Upload

Navigate to: /check-all-themes.php

This will show:

  • All users with themes in database
  • File paths and whether files exist
  • Generated URLs
  • HTML that SHOULD be rendered
⚠️ If no users shown: No theme was saved to database. Check:
  • Form was actually submitted (check form has enctype="multipart/form-data")
  • No validation errors shown after upload
  • File was selected before clicking Save

Step 2: Verify HTML Structure

After uploading theme:

  1. Go to your profile page: /profile
  2. Press F12 to open DevTools
  3. Right-click on the page background → Inspect
  4. Look for the <body> tag
Expected HTML structure: <body class="app-body has-bg theme-overlay-auto" style="background-image: url('/storage/themes/...'); background-size: cover; background-position: center; background-attachment: fixed; background-repeat: no-repeat;">
If you see: <body class="app-body"> (no "has-bg" class)
Then either:
  • Database wasn't saved (see Step 1)
  • Browser cache showing old page (Ctrl+Shift+Delete to clear)
  • auth()->user() not returning saved data

Step 3: Verify Image is Accessible

Test if image file can be downloaded:

If HTML shows: url('/storage/themes/a1b2c3d4.png')

Try opening in new tab: https://your-domain.com/storage/themes/a1b2c3d4.png

If image doesn't load: The public symlink might be broken.
Run in terminal: php artisan storage:link

Step 4: Check CSS in DevTools

  1. In DevTools, click Elements tab
  2. Select the <body> element
  3. Look at Styles panel on right
  4. You should see:
    • element.style - the inline style (should have background-image)
    • .app-body.has-bg - CSS rule setting background: none;
    • .app-body::before - the overlay gradient

Common Issues & Fixes

Issue 1: "Background shows default gradient, not my image"

Likely cause: Database not saving theme data

Fix:

  • Go to profile page
  • Upload image (should see preview)
  • Click Save button
  • Check for green success message
  • Hard refresh (Ctrl+Shift+Delete)
  • If still not working, check /check-all-themes.php to see if data saved

Issue 2: "See success message but background doesn't appear"

Likely cause: CSS conflict or browser cache

Fix:

  • Clear all browser cache: Ctrl+Shift+Delete
  • Close browser completely
  • Reopen and go to profile page
  • If still not working, check DevTools HTML/CSS (Step 2 & 4)

Issue 3: "Can see HTML has background-image but image doesn't load"

Likely cause: Image URL wrong or symlink broken

Fix:

  • Copy the URL from inline style
  • Test directly in browser: https://your-domain.com/storage/themes/filename.png
  • If image doesn't download, run: php artisan storage:link

Issue 4: "DevTools shows !important overriding background"

Likely cause: CSS has conflicting !important rules

Fix: This should be fixed in latest code. Clear cache and refresh.

Command Line Diagnostics

Run these in your project root:

# Check if storage symlink exists ls -la public/storage # Recreate symlink if broken php artisan storage:link # Check database for theme data php artisan tinker >>> App\Models\User::whereNotNull('theme_bg_path')->get() # Check files in storage ls -la storage/app/public/themes/

CSS Rules to Verify

The CSS should have these rules (in Styles tab in DevTools):

/* Default gradient (for pages without theme) */ .app-body { background: linear-gradient(135deg, #f3f4f6 0%, #ffffff 100%); } /* When theme active - clear default, show inline style */ .app-body.has-bg { background: none; } /* Overlay on top of background */ .app-body.has-bg::before { position: fixed; background: linear-gradient(180deg, rgba(2,6,23,0.35), rgba(2,6,23,0.55)); z-index: 1; } /* Content layer with semi-transparent white + blur */ .app-body.has-bg .app-main { background: rgba(255, 255, 255, 0.55) !important; backdrop-filter: blur(12px); }

Still Not Working?

Detailed checklist:

  1. ✅ Run /check-all-themes.php - verify data saved
  2. ✅ Hard refresh browser - clear cache
  3. ✅ Open DevTools - check console for errors
  4. ✅ Inspect body tag - verify HTML structure (step 2)
  5. ✅ Test image URL directly in browser
  6. ✅ Check CSS rules in DevTools (step 4)
  7. ✅ Verify no !important conflicts
  8. ✅ Check storage/app/public/themes/ folder exists with files
  9. ✅ Run: php artisan storage:link

If all pass but still not working: Check browser console for JavaScript errors and ensure no other CSS is overriding these rules.
